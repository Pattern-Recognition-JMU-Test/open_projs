# Current Projects & Theses

This repo is dedicated to give an easy-to-maintain solution of showing the opening projects information to students. 

The webpage ([https://pattern-recognition-jmu-test.github.io/open_projs/current_projects.html](https://pattern-recognition-jmu-test.github.io/open_projs/current_projects.html)) is hosted by GitHub Pages, so you can easily use markdown to update. 

This page link will be also visible in our [lab's official website](https://www.caidas.uni-wuerzburg.de/pr/) (currently WIP). So there we show the general information with less changes such as thesis submission guideline, and here we show the current projects information and the application process. 

For update and maintainance, please check [cheatsheet.md](cheatsheet.md) for more information.
